## 🧩 ¿Cómo funciona el Hangul?

A diferencia del alfabeto latino, las letras en coreano no se escriben en línea recta, sino que se agrupan en **bloques silábicos**. Cada bloque representa una sílaba y debe contener **mínimo una consonante y una vocal**.

## 🔤 Consonantes Básicas

| Letra | Nombre | Rom. Aproximada | Sonido similar en español |
| :---: | :---: | :---: | :--- |
| **ㄱ** | Giyeok (기역) | g / k | Entre 'g' (gato) y 'k' |
| **ㄴ** | Nieun (니은) | n | 'n' (nube) |
| **ㄷ** | Digeut (디귿) | d / t | Entre 'd' (dado) y 't' |
| **ㄹ** | Rieul (리을) | r / l | 'r' suave (pero al final suena como 'l') |
| **ㅁ** | Mieum (미음) | m | 'm' (mano) |
| **ㅂ** | Bieup (비읍) | b / p | Entre 'b' (barco) y 'p' |
| **ㅅ** | Siot (시옷) | s | 's' (sol) |
| **ㅇ** | Ieung (이응) | - / ng | Muda al inicio; sonido 'ng' (sing) al final |
| **ㅈ** | Jieut (지읒) | j / ch | 'ch' suave o 'j' inglesa (John) |

## 🧱 Estructura de un Bloque (Sílaba)

Cada bloque silábico sigue un orden de trazo (de arriba a abajo y de izquierda a derecha):

1. **Vocal Vertical** (ㅏ, ㅓ, ㅣ): La vocal se coloca a la **derecha** de la consonante.
   * `ㅂ` + `ㅏ` = **바** (ba)
2. **Vocal Horizontal** (ㅗ, ㅜ, ㅡ): La vocal se coloca **debajo** de la consonante.
   * `ㄱ` + `ㅗ` = **고** (go)

## 🔚 Batchim (Consonante Final)

Cualquier consonante situada en la posición inferior de un bloque recibe el nombre de **Batchim** (받침). Cambia o simplifica su sonido al final de la sílaba:

| Consonantes en Batchim | Sonido de salida | Ejemplo |
| :--- | :---: | :--- |
| **ㄱ, ㅋ, ㄲ** | **[K]** | 한**국** (Han-guk) |
| **ㄴ** | **[N]** | 안**녕** (An-nyeong) |
| **ㄷ, ㅅ, ㅈ, ㅊ, ㅌ, ㅎ, ㅆ** | **[T]** | **맛** (Mat) |
| **ㄹ** | **[L]** | **서울** (Se-ul) |
| **ㅁ** | **[M]** | **임** (Im) |
| **ㅂ, ㅍ** | **[P]** | **밥** (Bap) |
| **ㅇ** | **[NG]** | **강** (Gang) |
